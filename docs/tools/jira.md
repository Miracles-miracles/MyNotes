# Jira 项目管理

## 基本概念

### Issue (问题)

工作项的基本单位，如任务、Bug、需求等。

### Project (项目)

一组相关 Issue 的集合。

### Sprint (迭代)

短周期的开发循环，通常 1-4 周。

### Epic (史诗)

大型功能需求，可分解为多个 Story。

### Story (用户故事)

用户视角的功能需求。

### Task (任务)

具体的开发任务。

### Bug (缺陷)

需要修复的问题。

## Issue 状态流转

### 标准流程

```
待办 (To Do)
    ↓
进行中 (In Progress)
    ↓
代码审查 (Code Review)
    ↓
待验证 (Pending Verification)
    ↓
已完成 (Done)
```

### 特殊状态

- 阻塞 (Blocked)：等待其他工作完成
- 暂缓 (Deferred)：推迟到后续迭代
- 关闭 (Closed)：已完成并归档

## Issue 优先级

### 优先级等级

| 优先级 | 说明 | 示例 |
|--------|------|------|
| Blocker | 阻塞性问题，无法继续 | 系统崩溃 |
| Critical | 严重问题，影响核心功能 | 登录失败 |
| Major | 重要问题，影响部分功能 | 页面显示错误 |
| Minor | 次要问题，有替代方案 | 文案错误 |
| Trivial | 微小问题，不影响功能 | 样式微调 |

## Issue 类型

### 常用类型

- **Epic**：大型功能模块
- **Story**：用户需求
- **Task**：开发任务
- **Bug**：缺陷
- **Sub-task**：子任务

## 工作流程

### 创建 Issue

1. 选择项目
2. 选择 Issue 类型
3. 填写标题
4. 填写描述
5. 设置优先级和指派
6. 添加标签和附件

### Sprint 计划

1. 从待办列表中选择 Issue
2. 估算工作量（Story Points）
3. 分配到 Sprint
4. 设置负责人

### 日常跟踪

1. 更新 Issue 状态
2. 添加评论和附件
3. 记录工作时间
4. 关联相关 Issue

### Sprint 回顾

1. 总结完成情况
2. 分析未完成原因
3. 收集改进建议
4. 规划下一个 Sprint

## 搜索与筛选

### 快速搜索

```
project = MYPROJECT AND status = "In Progress"
```

### 高级搜索

- 按项目筛选
- 按状态筛选
- 按优先级筛选
- 按负责人筛选
- 按标签筛选

### 保存筛选

创建过滤器，保存常用的搜索条件。
