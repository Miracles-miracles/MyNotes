# XMind 思维导图

## 基本概念

### 中心主题

思维导图的核心主题，位于中心位置。

### 分支主题

从中心主题延伸出来的主要分支。

### 子主题

分支主题下的子节点。

### 自由主题

独立于主结构的主题，可以自由放置。

### 联系

连接两个主题的关联线，表示它们之间的关系。

## 常用结构

### 思维导图

最常用的结构，从中心向外辐射。

### 组织结构图

层级分明的树状结构，适合展示组织架构。

### 流程图

线性流程结构，适合展示步骤和流程。

### 鱼骨图

因果分析结构，适合分析问题原因。

### 矩阵图

二维矩阵结构，适合对比分析。

## 使用技巧

### 快捷键

```
Ctrl + N: 新建
Ctrl + S: 保存
Ctrl + Z: 撤销
Ctrl + Y: 重做

Tab: 添加子主题
Enter: 添加同级主题
Insert: 添加自由主题

Ctrl + D: 复制
Ctrl + X: 剪切
Delete: 删除

Ctrl + +: 放大
Ctrl + -: 缩小
Ctrl + 0: 适合窗口
```

### 样式设置

- **主题样式**：修改颜色、形状、边框
- **字体设置**：修改字体、大小、颜色
- **图标标记**：添加优先级、进度等图标
- **标签设置**：添加分类标签

### 主题关系

- **父子关系**：层级结构
- **联系关系**：关联线连接
- **摘要关系**：多个子主题的汇总

## 应用场景

### 需求分析

```
中心主题：项目需求
├── 功能需求
│   ├── 用户管理
│   ├── 权限管理
│   └── 数据统计
├── 非功能需求
│   ├── 性能要求
│   ├── 安全要求
│   └── 兼容性要求
└── 约束条件
    ├── 时间限制
    └── 资源限制
```

### 测试用例设计

```
中心主题：登录功能测试
├── 正常流程
│   ├── 正确账号密码
│   ├── 记住密码
│   └── 自动登录
├── 异常流程
│   ├── 账号不存在
│   ├── 密码错误
│   ├── 账号锁定
│   └── 网络异常
└── 边界情况
    ├── 空账号
    ├── 空密码
    ├── 超长字符
    └── 特殊字符
```

## 最佳实践

### 保持简洁

每个主题只包含一个核心概念。

### 使用关键词

避免冗长的句子，使用简洁的关键词。

### 层次分明

合理组织主题层级，保持结构清晰。

### 颜色区分

使用不同颜色区分不同类型的主题。

### 定期更新

根据项目进展及时更新思维导图。
