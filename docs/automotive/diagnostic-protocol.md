# 诊断协议

## 基本概念

### 诊断协议

用于车辆诊断和维护的通信协议。

### OBD (On-Board Diagnostics)

车载诊断系统，监测车辆运行状态。

### UDS (Unified Diagnostic Services)

统一诊断服务，ISO 14229 标准。

## OBD-II 标准

### 历史

- **OBD-I**：1988 年，美国加州标准
- **OBD-II**：1996 年，美国联邦标准

### 通信接口

| 接口 | 协议 |
|------|------|
| SAE J1850 PWM | 通用汽车 |
| SAE J1850 VPW | 福特、克莱斯勒 |
| ISO 9141-2 | 欧洲车 |
| ISO 14230-4 (KWP2000) | 欧洲车 |
| ISO 15765-4 (CAN) | 现代车辆 |

### 故障码格式

```
P0XXX - 动力系统
P1XXX - 制造商特定
P2XXX - 动力系统（扩展）
P3XXX - 动力系统（扩展制造商特定）

B0XXX - 车身系统
B1XXX - 制造商特定

C0XXX - 底盘系统
C1XXX - 制造商特定

U0XXX - 网络通信
U1XXX - 制造商特定
```

### 常用故障码

| 故障码 | 说明 |
|--------|------|
| P0300 | 随机/多缸失火 |
| P0171 | 系统过稀（缸组1） |
| P0174 | 系统过稀（缸组2） |
| P0420 | 催化转换器效率低 |
| P0500 | 车速传感器故障 |

## UDS 协议

### ISO 14229 标准

定义了统一诊断服务的规范。

### 服务 ID

| 服务 ID | 服务名称 |
|---------|----------|
| 0x10 | 会话控制 |
| 0x11 | ECU 复位 |
| 0x14 | 清除故障码 |
| 0x19 | 读取故障码 |
| 0x22 | 读取数据标识符 |
| 0x23 | 读取内存地址 |
| 0x24 | 读取故障码快照 |
| 0x27 | 安全访问 |
| 0x28 | 通信控制 |
| 0x2E | 写入数据标识符 |
| 0x31 | 例行程序控制 |
| 0x34 | 请求下载 |
| 0x35 | 请求上传 |
| 0x36 | 传输数据 |
| 0x37 | 请求传输退出 |
| 0x3D | 通用定时器管理 |

### 请求/响应格式

#### 请求

```
[服务ID] [子功能] [参数...]
```

#### 响应

```
[服务ID + 0x40] [子功能] [数据...]
```

### 会话控制

```
请求: 10 01          // 默认会话
响应: 50 01 00 01    // 肯定响应

请求: 10 02          // 编程会话
响应: 50 02 00 01    // 肯定响应

请求: 10 03          // 扩展会话
响应: 50 03 00 01    // 肯定响应
```

### 读取故障码

```
请求: 19 02          // 读取所有故障码
响应: 59 02 01 00    // 故障码数量
      P0300 00       // 故障码1
      P0420 00       // 故障码2
```

### 清除故障码

```
请求: 14 FF FF FF    // 清除所有故障码
响应: 54             // 肯定响应
```

### 读取数据标识符 (DID)

```
请求: 22 F1 90       // 读取车辆信息
响应: 62 F1 90       // 肯定响应
      56 41 55 54    // VIN 数据
```

### 安全访问

```
请求: 27 01          // 请求安全种子
响应: 67 01 12 34    // 返回种子

请求: 27 02 56 78    // 发送密钥
响应: 67 02          // 肯定响应（解锁成功）
```

## 诊断通信流程

### 典型流程

```
1. 建立诊断会话
   请求: 10 03
   响应: 50 03

2. 安全访问（如需）
   请求: 27 01
   响应: 67 01 [种子]
   请求: 27 02 [密钥]
   响应: 67 02

3. 执行诊断服务
   请求: 22 [DID]
   响应: 62 [DID] [数据]

4. 结束会话
   请求: 10 01
   响应: 50 01
```

### 否定响应

| 否定响应码 | 说明 |
|------------|------|
| 0x00 | 服务不支持 |
| 0x10 | 子功能不支持 |
| 0x11 | 消息长度错误 |
| 0x22 | 条件不满足 |
| 0x24 | 请求序列错误 |
| 0x33 | 安全访问被拒绝 |
| 0x35 | 无效密钥 |

## 最佳实践

### 诊断会话管理

- 使用合适的会话模式
- 操作完成后切换回默认会话

### 超时处理

- 设置合理的超时时间
- 处理通信异常

### 错误处理

- 检查响应码
- 处理否定响应
- 记录错误日志

### 安全性

- 安全访问密钥保密
- 限制诊断接口访问权限
