# CAN 通信原理

## 基本概念

### CAN (Controller Area Network)

控制器局域网，是一种串行通信总线标准。

### CAN 总线特点

- **多主节点**：每个节点都可以主动发送消息
- **差分信号**：使用差分电压传输，抗干扰能力强
- **仲裁机制**：通过 ID 优先级仲裁，避免冲突
- **错误检测**：自动检测和纠正传输错误
- **高可靠性**：广泛应用于汽车和工业控制领域

## CAN 物理层

### 总线结构

```
CAN_H ────●───●───●───●
           │   │   │   │
          ECU ECU ECU ECU
           │   │   │   │
CAN_L ────●───●───●───●
```

### 通信介质

- 双绞线
- 特性阻抗：120Ω

### 信号电平

| 总线状态 | CAN_H | CAN_L | 差分电压 |
|----------|-------|-------|----------|
| 隐性 (Idle) | 2.5V | 2.5V | 0V |
| 显性 (Dominant) | 3.5V | 1.5V | 2V |

## CAN 数据链路层

### 帧结构

#### CAN 2.0A (标准帧)

```
┌─────────┬──────┬──────────┬──────┬──────────┬─────────┬───────┐
│  帧起始  │ 仲裁域 │  控制域   │ 数据域  │  校验域   │  应答域  │ 帧结束  │
│  1 bit  │ 12 bit │  6 bit   │0-8 byte│  16 bit  │  2 bit  │ 7 bit  │
└─────────┴──────┴──────────┴──────┴──────────┴─────────┴───────┘
```

#### CAN 2.0B (扩展帧)

```
┌─────────┬──────────┬──────────┬──────┬──────────┬─────────┬───────┐
│  帧起始  │   仲裁域   │  控制域   │ 数据域  │  校验域   │  应答域  │ 帧结束  │
│  1 bit  │  29 bit  │  6 bit   │0-8 byte│  16 bit  │  2 bit  │ 7 bit  │
└─────────┴──────────┴──────────┴──────┴──────────┴─────────┴───────┘
```

### 仲裁机制

- 使用 ID 进行优先级仲裁
- ID 越小，优先级越高
- 显性位 (0) 优先于隐性位 (1)

### 帧类型

| 帧类型 | 说明 |
|--------|------|
| 数据帧 | 传输数据 |
| 遥控帧 | 请求数据 |
| 错误帧 | 报告错误 |
| 过载帧 | 延迟下一个帧 |

## CAN 协议版本

### CAN 2.0

- **2.0A**：标准帧格式，11 位 ID
- **2.0B**：扩展帧格式，29 位 ID

### CAN FD (Flexible Data Rate)

- 支持更长的数据域（最多 64 字节）
- 更高的数据传输速率
- 兼容 CAN 2.0

### CAN XL

- 更高的数据传输速率
- 更长的帧长度

## CAN 应用层协议

### ISO 15765 (Diagnostic over CAN)

用于汽车诊断通信。

### SAE J1939

用于商用车通信。

### CANopen

用于工业自动化。

### NMEA 2000

用于船舶通信。

## CAN 网络管理

### 节点状态

- **活动状态**：正常通信
- **休眠状态**：低功耗模式
- **唤醒状态**：从休眠唤醒

### 唤醒机制

- 总线唤醒：检测到总线活动
- 本地唤醒：本地事件触发

## CAN 诊断

### 故障码 (DTC)

存储在 ECU 中的故障信息。

### OBD-II

车载诊断系统，支持读取和清除故障码。

### UDS (Unified Diagnostic Services)

统一诊断服务，ISO 14229 标准。

## 常见问题

### 总线错误

- **位错误**：发送和接收的位不一致
- **填充错误**：违反位填充规则
- **CRC 错误**：校验和不匹配
- **格式错误**：帧格式不正确
- **应答错误**：未收到应答

### 总线负载

- 总线负载率 = 已用时间 / 总时间 × 100%
- 建议总线负载率不超过 30%

### 电磁兼容性 (EMC)

- 使用屏蔽双绞线
- 合理布置线束
- 增加终端电阻
