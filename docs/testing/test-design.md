# 用例设计方法

## 等价类划分

将输入数据划分为若干等价类，从每个等价类中选取代表性数据作为测试用例。

### 有效等价类

符合需求规格说明的输入数据集合。

### 无效等价类

不符合需求规格说明的输入数据集合。

### 示例

假设输入范围为 1-100 的整数：

```
有效等价类：1-100 的整数
无效等价类：<1 的数、>100 的数、小数、字符串、空值
```

## 边界值分析

对输入或输出的边界值进行测试，因为边界往往是错误的高发区。

### 边界值选择原则

- 上点：边界上的点
- 内点：边界内的点
- 离点：边界外的点

### 示例

输入范围为 1-100：

```
上点：1, 100
内点：50
离点：0, 101
```

## 场景法

模拟用户实际使用场景，设计测试用例。

### 基本流

用户正常操作的流程。

### 备选流

分支或异常情况。

### 示例

```
场景：用户登录系统
基本流：输入正确账号密码 → 登录成功
备选流1：账号不存在 → 提示错误
备选流2：密码错误 → 提示错误
备选流3：账号被锁定 → 提示联系管理员
```

## 错误推测法

基于经验和直觉，推测可能出现的错误。

### 常用推测方向

- 输入为空的情况
- 输入超长的情况
- 特殊字符输入
- 并发操作
- 网络异常
- 数据格式错误

## 因果图法

分析输入条件和输出结果之间的因果关系。

### 基本符号

- 恒等：若原因出现，则结果出现
- 非：若原因出现，则结果不出现
- 或：至少一个原因出现，则结果出现
- 与：所有原因出现，结果才出现

## 正交试验法

从大量测试用例中选取代表性的组合，减少测试次数。

### 适用场景

- 多因素多水平的测试
- 需要覆盖各种组合情况
